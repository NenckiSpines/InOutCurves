# Output figures

All generated figures are exported as PNG, PDF and SVG by default, with captions.
`notebook/` and `validation/` retain the established poster layouts and colors.
`examples/` contains the new paired, independent and grand-distance demonstrations.
The outputs shipped with this edition are labelled with their actual test/final
settings. Final-size simulation benchmarks were NOT run for this delivery.

Raster previews are not substitutes for the vector PDF/SVG files when enlarging
for a poster. Response axes deliberately say 'source units' until units have
been confirmed. Quantitative CSVs and run metadata are in `../dumps/`, not here.
